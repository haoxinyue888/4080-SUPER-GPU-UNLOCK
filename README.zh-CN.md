# RTX 4080 SUPER GPU Unlock — AD103 研究

**针对一张耕升（Gainward）GeForce RTX 4080 SUPER 16 GB 的独立、特定硬件适配研究。**

本仓库记录了我们如何研究已有的 GPU 计算性能解锁成果，并将相关方案适配到一张运行 Windows 11 的 RTX 4080 SUPER。重点是：**为什么需要适配、遇到了哪些实际故障、如何记录日志并保障启动流程，以及基准测试究竟证明了什么**。

> **这不是通用解锁工具。** 本项目是一份研究与复现参考资料，不提供可直接启动的 EFI 解锁程序，也不保证其他 RTX 4080 SUPER 型号兼容。GPU 固件实验可能导致显示输出中断、无法启动、数据丢失或硬件损坏。

## 实测结果

在一张耕升 RTX 4080 SUPER（AD103，16 GB）上，一次经人工明确确认的 UEFI 实验完成了 GPU 恢复，并将控制权交给 Windows。同一成功启动的 Windows 会话中，两次独立测试的 **FP16/BF16 稠密矩阵乘法（GEMM）** 吞吐量均高于原始未解锁基线。

| 8192³ 稠密 GEMM | 未解锁基线 | 解锁后测试 A | 解锁后测试 B |
|---|---:|---:|---:|
| FP16（有效 TFLOPS） | 101.303 | 171.552（+69.3%） | 168.488（+66.3%） |
| BF16（有效 TFLOPS） | 101.398 | 174.711（+72.3%） | 170.911（+68.6%） |

之后一次**未运行 USB 解锁流程的普通 Windows 重启**，性能回到了接近未解锁的水平。因此，**上述提升并未在那次重启后保留**。后续 **RUN06** 再次验证了 USB 优先启动时的 Windows 交接流程，但**没有单独保存标记为 RUN06 的性能测试结果**。

这些结果反映的是*数据已驻留显存时的矩阵乘法性能*，不能直接推导为游戏帧率、LLM 生成速度、一般应用性能、计算正确性或长期稳定性提升。详见[测试结果与方法](docs/RESULTS.zh-CN.md)。

## 本仓库包含什么、不包含什么

- **包含：** 独立撰写的案例研究、适配原因、经过脱敏的部分观测结果、验证检查点及性能测试方法。
- **不包含：** 具有解锁能力的 EFI 二进制文件、专有固件、GPU ROM/PROM 转储、原始私人日志、设备特定的内存地址或通用补丁包。
- **研究范围：** 与解锁直接相关的兼容性、故障分析、日志、人工确认、启动交接和计算性能变化；不讨论无关的 PC 故障排查。

**最初的 GPU 解锁技术来自上游研究者，而非本仓库原创。** 其中，Windows UEFI 方案的直接起点是 [TOTORONG/AD103_win_unlocker](https://huggingface.co/TOTORONG/AD103_win_unlocker)：该项目记录的是一张*改装为 32 GB 的非 SUPER 版 RTX 4080*。更完整的技术来源见[参考文献与致谢](REFERENCES.zh-CN.md)。
